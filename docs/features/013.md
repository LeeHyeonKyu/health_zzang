# 주차 면제 (휴식 신청)

## Problem
아파서, 출장, 경조사 등으로 특정 주에 운동이 불가능한 경우가 있다. 현재는 면제 개념이 없어서 무조건 벌금이 발생.

## Solution
- 인증 탭에서 "이번 주 면제 신청" 가능
- 사유 텍스트 + 증빙 첨부(선택)
- 즉시 적용 (승인 불필요)
- 면제된 주: target=0, 벌금/차감 계산에서 제외
- 기록/벌금 뷰에서 면제 표시 (🏥 아이콘 등)

## Scope

**Includes:**
- DB: `week_exemption` 테이블 (user_id, season_id, week_start, reason, media_r2_key)
- API: POST /api/exemption (신청), DELETE /api/exemption (취소)
- 인증 탭에 "이번 주 면제" 버튼
- 면제 신청 폼 (사유 + 첨부)
- 벌금 계산에서 면제 유저 제외
- 기록 주간 뷰에서 면제 표시
- 벌금 주간 상세에서 면제 표시
- 통계에서 면제 주 제외

**Excludes:**
- 부분 면제 (주 중 일부만)
- 승인 프로세스
- 면제 횟수 제한
