# 시즌 관리

<!-- 시즌을 생성/종료하고, 규칙을 설정하고, 누적 벌금과 주별 이벤트를 확인한다 -->

## Problem

크루는 일정 기간 단위(시즌)로 운영되고, 시즌마다 규칙이 다를 수 있다. 시즌별 벌금 누적과 정산이 필요하고, 과거 시즌도 돌아볼 수 있어야 한다.

## Value

시즌 단위 운영으로 벌금 정산의 명확한 경계를 만든다. 누적 벌금을 자동으로 보여주므로 회식 때 정산이 간편해진다. 과거 시즌 아카이브로 크루 히스토리가 남는다.

## Solution

- `/season` 페이지에서 현재 시즌 현황 + 과거 시즌 목록
- `/settings`에서 시즌 생성/종료, 규칙 설정/override
- 시즌 생성 시 default 규칙(목표 횟수, penalty_per_miss, reward_per_extra) 설정
- 특정 주만 규칙 override 가능

## Scope

**Includes:**
- 시즌 생성 (이름, 시작일, default 규칙: 목표 횟수, penalty_per_miss, reward_per_extra)
- 시즌 종료 (종료일 기록, 시즌 비활성화)
- 특정 주 규칙 override (WeeklyRule 생성)
- 시즌 현황 (`/season`) — 시즌 누적 벌금, 크루원별 누적, 주별 벌금 이벤트
- 과거 시즌 아카이브 열람
- 동시에 1개 시즌만 활성

**Excludes:**
- 시즌 삭제
- 시즌 간 데이터 이동
- 시즌 자동 시작/종료

## User Stories & Acceptance Criteria

### Story 1: 시즌 생성

**As a** 크루원, **I want** 새 시즌을 시작하고 규칙을 정하고 **so that** 크루가 새로운 기간의 운동을 시작할 수 있다.

**Scenario:**
- Given: 활성 시즌이 없음
- When: `/settings`에서 시즌 이름, 시작일, default 규칙 입력 후 생성
- Then: 새 시즌이 활성화되고 인증 등록 가능

**Acceptance Criteria:**
- [ ] 시즌 이름, 시작일, 목표 횟수, penalty_per_miss, reward_per_extra 입력 후 생성 — verify: unit test (level: fast)
- [ ] 이미 활성 시즌이 있으면 새 시즌 생성 불가 — verify: unit test (level: fast)

**Edge Cases & Errors:**
- [ ] 필수 항목(이름, 목표 횟수, penalty_per_miss) 누락 시 에러 — verify: unit test (level: fast)
- [ ] reward_per_extra는 optional (기본값 0) — verify: unit test (level: fast)

### Story 2: 시즌 종료

**As a** 크루원, **I want** 시즌을 종료하고 **so that** 벌금을 정산하고 새 시즌을 시작할 수 있다.

**Scenario:**
- Given: 활성 시즌 존재
- When: `/settings`에서 시즌 종료 버튼 클릭
- Then: 시즌이 비활성화, 종료일 기록, 아카이브로 이동

**Acceptance Criteria:**
- [ ] 시즌 종료 시 종료일 기록, is_active = false — verify: unit test (level: fast)
- [ ] 종료된 시즌의 인증/규칙 데이터는 보존 — verify: unit test (level: fast)

### Story 3: 주간 규칙 override

**As a** 크루원, **I want** 특정 주의 규칙을 바꾸고 **so that** 바쁜 주에 목표를 조정할 수 있다.

**Scenario:**
- Given: 활성 시즌, 이번 주는 다들 바쁨
- When: `/settings`에서 해당 주 목표를 2회로 변경
- Then: 해당 주만 override 규칙 적용, 나머지 주는 default 유지

**Acceptance Criteria:**
- [ ] 특정 주의 규칙을 override하면 해당 주만 새 규칙 적용 — verify: unit test (level: fast)
- [ ] override가 없는 주는 시즌 default 규칙 적용 — verify: unit test (level: fast)

### Story 4: 시즌 현황 및 아카이브

**As a** 크루원, **I want** 시즌 누적 벌금과 주별 이벤트를 보고 **so that** 회식 때 정산할 수 있다.

**Scenario:**
- Given: 시즌이 4주 진행됨
- When: `/season` 접속
- Then: 크루원별 시즌 누적 벌금, 주별 벌금 이벤트 표시

**Acceptance Criteria:**
- [ ] 크루원별 시즌 누적 벌금 (주별 합산) 표시 — verify: unit test (level: fast)
- [ ] 주별 벌금 이벤트 목록 (어떤 주에 누가 얼마) 표시 — verify: unit test (level: fast)
- [ ] 과거 시즌 목록 표시 및 선택하면 해당 시즌 현황 열람 — verify: unit test (level: fast)
