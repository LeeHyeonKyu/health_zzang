# 내 기록 히스토리

<!-- 내 과거 운동 인증 내역을 사진과 함께 열람한다 -->

## Problem

인증을 올렸지만 과거 기록을 다시 보려면 방법이 없다. 카카오톡에서는 채팅에 묻혀서 찾기 어렵다.

## Value

내 운동 기록이 한곳에 정리되어 있으면 동기부여가 된다. "지난달에 얼마나 했지?" 같은 궁금증을 바로 해결.

## Solution

`/history` 페이지에서 내 인증 목록을 날짜순으로 표시. 각 항목에 날짜, 사진 썸네일, 운동 내용(있으면) 표시. 사진 클릭 시 원본 열람.

## Scope

**Includes:**
- 내 인증 목록 (`/history`) — 날짜 역순
- 각 항목: 날짜, 사진/영상 썸네일, 운동 내용 텍스트
- 사진/영상 클릭 시 원본 보기
- 시즌별 필터

**Excludes:**
- 인증 수정/삭제
- 통계/그래프
- 다른 크루원 기록 (별도 feature)

## User Stories & Acceptance Criteria

**As a** 크루원, **I want** 내 과거 운동 인증 기록을 보고 **so that** 운동 습관을 돌아볼 수 있다.

**Scenario:**
- Given: 로그인 상태, 인증 기록이 존재
- When: `/history` 접속
- Then: 내 인증 목록이 날짜 역순으로 표시, 사진 썸네일 포함
