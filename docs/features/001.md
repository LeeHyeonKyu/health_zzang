# 로그인 및 계정 사전 생성

<!-- 크루장이 미리 생성한 계정으로 크루원이 로그인만 하면 바로 서비스를 이용할 수 있다 -->

## Problem

서비스를 사용하려면 인증이 필요하지만, 12명의 신뢰 기반 크루에게 "회원가입" 절차는 불필요한 진입 장벽이다. 가입 폼, 이메일 인증 등은 마찰만 늘린다.

## Value

크루원은 카카오톡으로 받은 ID/PW를 입력하기만 하면 된다. 가입 절차가 아예 없으므로 "최소 마찰" 원칙(PROJECT.md NON-NEGOTIABLE)을 가장 강하게 지킨다. 한 번 로그인하면 재로그인 없이 계속 사용 가능.

## Solution

- 크루장이 Supabase Admin API 또는 스크립트로 크루원 계정을 미리 생성 (닉네임, 이메일, 비밀번호)
- 생성된 계정은 default crew에 자동 연결
- 크루원은 `/login` 페이지에서 ID/PW 입력 후 로그인
- Supabase Auth의 refresh token으로 세션 영구 유지

## Scope

**Includes:**
- 로그인 화면 (`/login`) — ID/PW 입력, 로그인 버튼
- 세션 유지 (재로그인 금지 원칙 — Supabase Auth refresh token)
- 로그아웃
- 계정 사전 생성 스크립트 (Supabase Admin API 활용)
- 생성 시 default crew 자동 연결

**Excludes:**
- 회원가입 페이지 / 셀프 가입
- 초대 코드
- 소셜 로그인 (카카오 등)
- 비밀번호 찾기/변경
- 프로필 이미지, 회원 탈퇴

## User Stories & Acceptance Criteria

### Story 1: 크루원 로그인

**As a** 크루원, **I want** 받은 ID/PW로 로그인 **so that** 운동 인증 서비스를 이용할 수 있다.

**Scenario:**
- Given: 크루장이 미리 생성한 계정이 존재함
- When: 로그인 화면에서 ID/PW 입력 후 로그인 버튼 클릭
- Then: 대시보드(`/`)로 이동, 이후 재로그인 불필요

**Acceptance Criteria:**
- [ ] 올바른 ID/PW로 로그인 시 대시보드(`/`)로 이동 — verify: unit test (level: fast)
- [ ] 로그인 후 브라우저를 닫았다 열어도 세션 유지 — verify: unit test, Supabase refresh token 동작 확인 (level: fast)

**Edge Cases & Errors:**
- [ ] 잘못된 비밀번호 입력 시 에러 메시지 표시 — verify: unit test (level: fast)
- [ ] 존재하지 않는 ID 입력 시 에러 메시지 표시 — verify: unit test (level: fast)
- [ ] ID 또는 PW 빈 칸 제출 시 폼 유효성 검사 — verify: unit test (level: fast)

### Story 2: 계정 사전 생성

**As a** 크루장(서비스 운영자), **I want** 크루원 계정을 미리 만들어두고 **so that** 크루원이 가입 없이 바로 로그인할 수 있다.

**Scenario:**
- Given: Supabase 프로젝트가 설정되어 있음
- When: 스크립트로 닉네임/이메일/비밀번호를 전달하여 계정 생성
- Then: 닉네임이 설정되고 default crew에 연결된 계정이 생성됨

**Acceptance Criteria:**
- [ ] 계정 생성 스크립트가 닉네임/이메일/비밀번호를 받아 Supabase에 유저 생성 — verify: unit test (level: fast)
- [ ] 생성된 계정이 default crew에 자동 연결 — verify: unit test (level: fast)

## Design Intent

| Step | User Action | Ideal Outcome | Design Decision | QA Verification |
|------|-------------|---------------|-----------------|-----------------|
| 1 | `/login` 접속 | ID/PW 입력 폼이 보임 | 폼 필드 2개 + 버튼 1개. 최소 UI | 폼 렌더링 확인 |
| 2 | ID/PW 입력 후 로그인 클릭 | 대시보드로 이동 | 로딩 중 버튼 비활성화 (중복 제출 방지) | 로그인 성공 후 `/` 리다이렉트 확인 |
| 3 | 잘못된 정보 입력 | 에러 메시지 표시 | 인라인 에러, 입력값 유지 (다시 입력 안 해도 됨) | 에러 메시지 노출 + 입력값 유지 확인 |

**Key States:**

| State | Trigger | User Sees |
|-------|---------|-----------|
| Empty | 최초 접속 | ID/PW 입력 폼, placeholder "이메일", "비밀번호" |
| Error | 잘못된 로그인 시도 | "이메일 또는 비밀번호가 올바르지 않습니다" + 입력값 유지 |
