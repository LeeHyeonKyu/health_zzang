# 크루원 기록 열람

<!-- 다른 크루원의 운동 인증 기록을 사진/영상과 함께 열람한다 -->

## Problem

카카오톡에서는 다른 사람의 운동 기록을 한눈에 보기 어렵다. 채팅에 섞여 있어서 "이 사람이 이번 달에 얼마나 했지?"를 확인하려면 스크롤해야 한다.

## Value

크루원 간 동기부여. 다른 사람의 기록과 사진을 보면 자극이 되고, 크루 내 유대감이 강화된다.

## Solution

대시보드에서 크루원 이름 클릭 → `/members/:id`로 이동. 해당 크루원의 인증 목록(날짜, 사진/영상, 텍스트)을 열람.

## Scope

**Includes:**
- 크루원 기록 페이지 (`/members/:id`)
- 해당 크루원의 인증 목록 (날짜 역순)
- 사진/영상 원본 열람
- 시즌별 필터

**Excludes:**
- 좋아요/댓글
- 크루원 프로필 상세
- 크루원 간 비교 통계

## User Stories & Acceptance Criteria

**Scenario:**
