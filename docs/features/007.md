# 비밀번호 변경

<!-- 크루원이 자신의 비밀번호를 변경할 수 있다 -->

## Problem

초기 비밀번호는 크루장이 설정한 것이라 크루원이 원하는 비밀번호로 바꿀 수 없다.

## Value

크루원이 본인만 아는 비밀번호로 변경하여 보안을 강화하고, 기억하기 쉬운 비밀번호를 설정할 수 있다.

## Solution

`/settings` 페이지 하단에 비밀번호 변경 섹션 추가. 새 비밀번호 입력 → Supabase Auth `updateUser`로 변경.

## Scope

**Includes:**
- 새 비밀번호 입력 + 확인 입력
- Supabase Auth로 비밀번호 업데이트

**Excludes:**
- 현재 비밀번호 확인 (이미 로그인 상태이므로 불필요)
- 비밀번호 찾기 (이메일 기반 리셋)
- 비밀번호 강도 표시
