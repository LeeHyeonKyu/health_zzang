# 주간 대시보드 및 벌금 자동 집계

<!-- 이번 주 크루원별 인증 현황과 벌금을 자동으로 계산하여 보여준다 -->

## Problem

현재 한 사람이 매주 수동으로 집계한다. 누가 몇 번 했는지, 벌금이 얼마인지를 사람이 세야 한다. 이 프로젝트의 존재 이유가 이 집계 자동화다.

## Value

로그인하면 바로 보이는 대시보드. "이번 주 내가 몇 번 했지?" "벌금이 얼마지?"를 아무도 집계하지 않아도 자동으로 확인. PROJECT.md의 성공 기준: "카카오톡에서 투표/집계가 더 이상 발생하지 않는다."

## Solution

`/` (홈) 페이지에 이번 주 크루원별 인증 횟수와 벌금을 표시. 벌금은 양방향 — 미달 시 벌금(+), 초과 달성 시 차감(-). 별도 테이블 없이 Workout 수와 규칙을 비교해 실시간 계산.

**벌금 계산 공식:**
- `missed = max(0, target_count - workout_count)`
- `extra = max(0, workout_count - target_count)`
- `penalty = (missed × penalty_per_miss) - (extra × reward_per_extra)`
- 결과가 음수면 차감(보상), 양수면 벌금

## Scope

**Includes:**
- 주간 현황 대시보드 (`/`) — 로그인 후 첫 화면
- 크루원별 이번 주 인증 횟수 표시
- 이번 주 규칙 (목표 횟수, 회당 벌금, 회당 차감)
- 크루원별 벌금 자동 계산 (양방향: +벌금 / -차감)
- 주간 총 벌금 합계

**Excludes:**
- 시즌 누적 벌금 (시즌 관리 feature)
- 과거 주 열람
- 크루원 기록 상세 열람 (별도 feature)
- 규칙 수정 기능 (별도 feature)

**As a** 크루원, **I want** 이번 주 모든 크루원의 인증 현황을 한눈에 보고 **so that** 내 진행 상황과 벌금을 바로 알 수 있다.

- Then: 크루원별 인증 횟수, 벌금/차감 금액, 이번 주 규칙이 표시

**Acceptance Criteria:**

### Story 2: 벌금 계산 정확성

**As a** 크루원, **I want** 벌금이 정확히 계산되고 **so that** 회식 때 정산에 이의가 없다.

**Scenario:**
- Given: 주간 규칙 — 목표 3회, 벌금 2000원/회, 차감 1000원/회
- When: 크루원 A가 1회, B가 3회, C가 5회 인증
- Then: A = +4000원, B = 0원, C = -2000원

**Acceptance Criteria:**
- [ ] 위 시나리오 계산 결과가 정확 — verify: unit test (level: fast)
- [ ] 벌금 0원인 크루원도 0원으로 표시 (빈 칸 아님) — verify: unit test (level: fast)
