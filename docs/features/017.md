## Problem

크루원들이 앱을 사용하면서 SNS와 유사한 소통 패턴을 기대하게 됐다. 다른 크루원의 운동 인증을 보고 반응을 남기고 싶지만, 현재 앱에는 그런 수단이 없어서 결국 카카오톡 단톡방으로 돌아가게 된다.

## Value

카카오톡 없이도 피드 안에서 응원/공감/간단한 대화가 가능해진다. PROJECT.md의 핵심 목표인 "카카오톡 대체"를 소통 측면에서 보강.

## Solution

1. **이모지 반응** — 고정 이모지 세트(💪🔥❤️👏😂👍🎉💯), 슬랙 스타일 카운트 + 토글, 한 명이 여러 이모지 동시 가능
2. **댓글** — 플랫 구조, 시간순 나열, 본인 댓글만 수정/삭제

## Scope

**Includes:** 이모지 반응(고정 세트, 토글, 카운트, 피드 카드 요약), 댓글(CRUD, 플랫), reaction/comment 테이블 + RLS

**Excludes:** 대댓글, 자유 이모지, 실시간 업데이트, 알림, 댓글 이모지 반응, 댓글 미디어 첨부
