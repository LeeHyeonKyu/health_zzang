# 뷰 구조 전면 재설계

<!-- 전체 페이지 구조를 목적별로 재편성하고, 각 뷰의 역할을 명확히 한다 -->

## Problem

현재 뷰 구조가 기능 추가 과정에서 유기적으로 쌓여 일관성이 없다. 홈/피드/내기록/시즌/설정이 역할이 겹치거나 접근 경로가 불명확하다.

## Solution — 5탭 구조

### 하단 네비게이션 (5탭)

| 탭 | 아이콘 | 페이지 | 핵심 역할 |
|---|---|---|---|
| **기록** | 📋 | `/records` | 크루 전체/개인 기록 열람 (주간/월간/피드 뷰) |
| **인증** | ➕ | `/workout/new` | 운동 인증 등록 (가장 중요한 액션) |
| **벌금** | 💰 | `/penalty` | 벌금 현황 (시즌 누적 + 주간 상세) |
| **통계** | 📊 | `/stats` | 시즌 통계 (운동 횟수, 평균, 랭킹) |
| **설정** | ⚙️ | `/settings` | 시즌 설정 + 개인 설정 |

### 각 뷰 상세 설계

## 1. 인증 탭 (`/workout/new`)

**목적:** 운동 인증 등록 — 서비스의 핵심 액션

**구성:**
- 날짜 선택 (기본: 오늘, 과거 날짜 가능, 미래 불가)
- 사진/영상 업로드 (필수, 복수 가능)
- 운동 내용 메모 (선택)
- 제출 버튼

**Design Intent:**
- 하단 네비 중앙에 배치 — 가장 자주 쓰는 액션이므로 인스타그램의 + 버튼처럼 강조
- 제출 후 기록 탭으로 이동 (방금 올린 기록 확인)

---

## 2. 기록 탭 (`/records`)

**목적:** 운동 기록 열람 — 크루 전체 또는 특정 개인의 기록을 다양한 뷰로

**구성:**

### 상단 컨트롤
- **뷰 전환**: 주간 | 월간 | 피드 (3개 토글)
- **필터**: 전체 크루 ↔ 내 기록만 (토글)
- 특정 크루원 탭 시 해당 크루원 기록만 (SNS 프로필 개념)

### 주간 뷰 (기본)
- ← 이전 주 / 이번 주 / 다음 주 → 네비게이션
- 크루원별 해당 주 인증 날짜 표시 (✓ 마크 또는 점)
- 크루원 이름 탭 → 해당 크루원 프로필(기록만 필터)

### 월간 뷰
- 달력 그리드 (기존 calendar-view 활용)
- "내 기록만" 토글 시 내 운동한 날만 표시
- "전체" 시 크루원별 색상 점으로 표시
- 날짜 탭 → 해당 날 인증 카드 표시

### 피드 뷰
- 인스타그램 스타일 카드 (사진 크게 + 닉네임 + 날짜 + 메모)
- "내 기록만" 토글 시 내 피드만
- 크루원 닉네임 탭 → 해당 크루원 프로필

### 크루원 프로필
- 상단: 닉네임 + 시즌 운동 횟수 + 벌금 합계
- 하단: 해당 크루원의 피드 (사진 카드 목록)
- ← 뒤로가기로 전체 기록으로 복귀

---

## 3. 벌금 탭 (`/penalty`)

**목적:** 벌금 현황 한눈에 — 회식 때 정산용

**구성:**

### 시즌 누적 뷰 (기본)
- 크루원별 시즌 누적 벌금 테이블 (많은 순 정렬)
- 크루 전체 합계
- + / - 색상 구분 (벌금 빨강, 차감 초록)

### 주간 상세 뷰
- ← 이전 주 / 이번 주 → 네비게이션
- 해당 주 규칙 표시 (목표 N회, 벌금 N원, 차감 N원)
- 크루원별: 인증 횟수 / 벌금 금액
- 목표 달성 여부 시각적 표시

### 뷰 전환
- 상단: 누적 | 주간 (2탭)

---

## 4. 통계 탭 (`/stats`)

**목적:** 시즌 통계 — 동기부여 + 트렌드 확인

**구성:**
- 시즌 요약 카드: 시즌명, 경과일수, 참여 인원
- 내 통계: 총 운동 횟수, 주당 평균, 연속 운동일, 총 벌금/차감
- 크루 랭킹: 운동 횟수 순 / 벌금 적은 순
- 주간 트렌드: 크루 전체 주당 평균 인증 수 추이

---

## 5. 설정 탭 (`/settings`)

**목적:** 시즌 + 개인 설정

**구성 (2탭):**

### 시즌 설정 탭
- 현재 시즌 정보 (이름, 시작일, 종료일)
- 시즌 생성/종료
- 기본 벌금 규칙 (목표 횟수, 미달 벌금, 초과 차감) — 1,000원 단위
- 주간 규칙 override (이번 주 + 과거 주 열람/수정)

### 개인 설정 탭
- 비밀번호 변경
- 로그아웃

## Scope

**Includes:**
- 하단 5탭 재구성 (기록/인증/벌금/통계/설정)
- 기록 탭: 주간/월간/피드 뷰 + 전체/내기록 토글 + 크루원 프로필
- 벌금 탭: 시즌 누적 + 주간 상세 (주 네비게이션)

- 인증 탭: 기존 유지

**Excludes:**
