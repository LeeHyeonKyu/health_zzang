# 운동 인증 등록

<!-- 크루원이 날짜를 선택하고 사진/영상을 올려 운동 인증을 등록한다 -->

## Problem

크루원이 운동을 했다는 것을 증명할 방법이 없다. 현재는 카카오톡 채팅방에 사진을 올리지만, 채팅에 묻히고 집계도 안 된다.

## Value

운동 인증의 단일 진입점. 여기서 올린 기록이 주간 대시보드와 벌금 집계의 원천 데이터가 된다. "링크 클릭 → 날짜 선택 → 사진 올리기 → 끝" — 카카오톡보다 간단한 흐름.

## Solution

`/workout/new` 페이지에서 날짜 선택 + 사진/영상 업로드. 사진은 R2에 presigned URL로 직접 업로드(서버 경유 없음). 하루 1건 제한. 운동 내용 텍스트는 optional.

## Scope

**Includes:**
- 운동 인증 등록 페이지 (`/workout/new`)
- 날짜 선택 (기본값: 오늘)
- 사진/영상 업로드 (R2 presigned URL, 개수 제한 없음)
- 영상은 720p 최적화, 최대 10MB
- 운동 내용 텍스트 (optional)
- 하루 1건 제한
- 활성 시즌에만 인증 가능

**Excludes:**
- 인증 수정/삭제
- 미래 날짜 인증
- 사진 필터/편집
- 업로드 진행률 표시

## User Stories & Acceptance Criteria

### Story 1: 운동 인증 등록

**As a** 크루원, **I want** 운동한 날짜와 사진을 올려서 인증 **so that** 주간 목표에 반영되고 벌금을 피할 수 있다.

**Scenario:**
- Given: 로그인 상태, 활성 시즌 존재
- When: `/workout/new`에서 날짜 선택 → 사진 첨부 → 제출
- Then: 인증이 저장되고 대시보드에 반영

**Acceptance Criteria:**
- [ ] 날짜 선택(기본 오늘) + 사진 1장 이상 첨부 후 제출하면 인증 저장 — verify: unit test (level: fast)
- [ ] 사진이 R2에 presigned URL로 직접 업로드됨 (서버 경유 없음) — verify: unit test (level: fast)
- [ ] 제출 후 대시보드(`/`)로 이동 — verify: unit test (level: fast)
- [ ] 운동 내용 텍스트는 optional — 비워도 제출 가능 — verify: unit test (level: fast)

**Edge Cases & Errors:**
- [ ] 사진 없이 제출 시 에러 메시지 ("사진을 1장 이상 올려주세요") — verify: unit test (level: fast)
- [ ] 같은 날짜에 이미 인증이 있으면 에러 메시지 ("이미 인증한 날짜입니다") — verify: unit test (level: fast)
- [ ] 미래 날짜 선택 불가 — verify: unit test (level: fast)
- [ ] 활성 시즌이 없으면 인증 불가 — verify: unit test (level: fast)
- [ ] 10MB 초과 영상 업로드 시 에러 메시지 — verify: unit test (level: fast)

### Story 2: 여러 장 사진 업로드

**As a** 크루원, **I want** 사진/영상을 여러 장 올리고 **so that** 운동 내용을 충분히 공유할 수 있다.

**Scenario:**
- Given: 인증 등록 페이지
- When: 사진 3장 + 영상 1개 첨부 후 제출
- Then: 모든 미디어가 R2에 저장되고 인증에 연결

**Acceptance Criteria:**
- [ ] 여러 개의 사진/영상을 한 번에 첨부 가능 — verify: unit test (level: fast)
- [ ] 각 미디어가 개별 presigned URL로 R2에 업로드 — verify: unit test (level: fast)

## Approach

- presigned URL 패턴: 클라이언트 → `/api/media/upload-url` → R2 presigned URL 반환 → 클라이언트가 R2에 직접 PUT
- Workout 레코드와 Media 레코드를 트랜잭션으로 저장
- 날짜 유효성 검사: 서버 사이드에서도 미래 날짜/중복 체크

## Assumptions

- R2 presigned URL이 Vercel serverless에서 문제없이 생성된다 — 불가 시: 서버 경유 업로드로 전환
- 영상 720p 최적화가 클라이언트에서 가능하다 — 불가 시: 용량 제한(10MB)만 적용
