# 반응형 레이아웃 통일

<!-- 모든 페이지와 탭의 콘텐츠 너비를 일관되게 만들고, 모바일/PC에서 적절한 크기를 적용한다 -->

## Problem

현재 레이아웃이 여러 곳에서 불일치:
1. 공통 레이아웃의 `max-w-lg`(512px)가 PC에서 너무 좁음
2. 설정 탭 간 콘텐츠 너비가 다름 (벌금 규칙 탭은 넓고, 내 계정 탭은 좁음)
3. 홈과 내 기록 페이지의 콘텐츠 크기가 미묘하게 다름
4. 모바일에서는 적절하지만 PC에서는 콘텐츠가 화면의 극소 부분만 차지

## Value

어떤 페이지에서든, 어떤 기기에서든 동일한 너비감과 여백. 모바일에서는 화면을 꽉 채우고, PC에서는 적당한 너비의 중앙 정렬 카드.

## Solution

- 공통 레이아웃의 max-width를 반응형으로: 모바일은 full-width, PC는 `max-w-xl`(576px) 또는 `max-w-2xl`(672px)
- 모든 페이지 콘텐츠가 레이아웃의 `<main>` 안에서 100% 너비를 사용
- 설정 탭 내부 폼도 100% 너비로 통일
- 카드/테이블 컴포넌트의 너비를 `w-full`로 통일

## Scope

**Includes:**
- 공통 레이아웃 (`(app)/layout.tsx`) max-width 반응형 적용
- 모든 페이지 콘텐츠 너비 100% 통일
- 설정 탭 간 너비 일관성
- 헤더/하단 네비 반응형
- PC에서 적절한 여백/중앙 정렬

**Excludes:**
- 페이지별 고유 디자인 변경
- 다크 모드
- 태블릿 전용 레이아웃

## User Stories & Acceptance Criteria

**As a** 크루원, **I want** 모든 페이지가 같은 너비로 보이고 **so that** 페이지 이동 시 시각적으로 안정적이다.

**Acceptance Criteria:**
- [ ] 모든 페이지의 콘텐츠 영역이 동일한 max-width를 가진다 — verify: visual (level: fast)
- [ ] 설정 탭 전환 시 콘텐츠 너비가 변하지 않는다 — verify: visual (level: fast)
- [ ] 홈, 내 기록, 시즌, 설정, 인증 페이지 모두 동일한 레이아웃 — verify: visual (level: fast)

### Story 2: 반응형 대응

**As a** 크루원, **I want** 모바일과 PC 모두에서 적절한 크기로 보이고 **so that** 어느 기기에서든 편하게 쓸 수 있다.

**Acceptance Criteria:**
