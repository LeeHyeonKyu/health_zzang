# 달력 뷰 + 크루 피드 뷰

<!-- 운동 기록을 달력으로 한눈에 보고, 크루 전체 최근 인증을 인스타그램 피드처럼 본다 -->

## Problem

현재 기록은 날짜 역순 리스트만 제공. "이번 달에 며칠 운동했지?"를 한눈에 파악하기 어렵고, 다른 크루원들이 최근 뭘 했는지 모아보는 곳이 없다.

## Value

달력 뷰로 한 달의 운동 빈도를 시각적으로 확인 — 동기부여. 크루 피드로 다른 크루원의 인증을 실시간으로 보며 자극 받음 — 카카오톡 채팅방에서 사진 공유하던 경험의 대체.

## Solution

1. **달력 뷰**: 내 기록(`/history`)과 크루원 기록(`/members/:id`)에 월간 달력 표시. 운동한 날에 점 표시. 날짜 탭 시 해당 날의 인증 사진/메모가 아래에 표시.
2. **크루 피드 뷰**: 크루 전체의 최근 인증을 시간순 카드로 표시. 사진 크게 + 닉네임 + 날짜 + 메모. 하단 네비에 피드 탭 추가 또는 홈에서 접근.
3. 기존 리스트 뷰와 달력 뷰는 토글로 전환.

## Scope

**Includes:**
- 달력 뷰 컴포넌트 (월간 그리드, 운동한 날 점 표시, 이전/다음 월 이동)
- 달력에서 날짜 탭 시 해당 인증 상세 표시
- 내 기록 + 크루원 기록에 리스트/달력 뷰 토글
- 크루 피드 페이지 (`/feed`) — 크루 전체 최근 인증 카드형
- 피드 카드: 사진 크게 + 닉네임 + 날짜 + 메모
- 하단 네비에 피드 탭 추가

**Excludes:**
- 좋아요/댓글
- 무한 스크롤/페이지네이션
- 사진 편집/필터
- 피드 알림

## User Stories & Acceptance Criteria

### Story 1: 달력으로 운동 빈도 확인

**As a** 크루원, **I want** 달력에서 운동한 날을 한눈에 보고 **so that** 이번 달 얼마나 꾸준히 했는지 파악할 수 있다.

**Scenario:**
- Given: 로그인 상태, 인증 기록 존재
- When: 내 기록에서 달력 뷰 선택
- Then: 월간 달력에 운동한 날이 표시됨

**Acceptance Criteria:**
- [ ] 월간 달력 그리드에 운동한 날이 점 또는 색상으로 표시 — verify: unit test (level: fast)
- [ ] 이전/다음 월 이동 가능 — verify: unit test (level: fast)
- [ ] 날짜 탭 시 해당 날의 인증 사진/메모가 달력 아래에 표시 — verify: unit test (level: fast)
- [ ] 리스트 뷰 ↔ 달력 뷰 토글 — verify: unit test (level: fast)

**Edge Cases & Errors:**
- [ ] 인증이 없는 달은 빈 달력 표시 — verify: unit test (level: fast)
- [ ] 크루원 기록(`/members/:id`)에서도 동일하게 동작 — verify: unit test (level: fast)

### Story 2: 크루 피드로 최근 인증 구경

**As a** 크루원, **I want** 크루 전체의 최근 인증을 피드로 보고 **so that** 다른 크루원이 뭘 했는지 알고 동기부여를 받는다.

**Scenario:**
- Given: 로그인 상태, 크루원들의 인증 기록 존재
- When: 피드 탭 클릭
- Then: 최근 인증이 시간순(최신 먼저) 카드형으로 표시

**Acceptance Criteria:**
- [ ] 크루 전체 인증이 최신순으로 표시 — verify: unit test (level: fast)
- [ ] 각 카드에 사진(크게), 닉네임, 날짜, 메모 표시 — verify: unit test (level: fast)
- [ ] 하단 네비에 피드 탭 존재 — verify: unit test (level: fast)

**Edge Cases & Errors:**
- [ ] 인증이 없으면 "아직 인증이 없습니다" 안내 — verify: unit test (level: fast)
